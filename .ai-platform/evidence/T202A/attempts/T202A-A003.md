# T202A-A003 Attempt

## Outcome

- Status: GREEN implementation complete; review remediation required.
- Scope: only `authority.rs` and `authority_schema.rs` changed in this attempt.
- Acceptance: not accepted. The stale/concurrency findings closed, but
  independent review found one Medium connection-pragma regression.

## TDD Evidence

Three deterministic RED tests exited with the expected behavior failures:

- stale non-Unconfigured state consumed entropy or created a replacement DB;
- open/confirm interleaving combined rows from different SQLite snapshots;
- exact committed retry succeeded after application identity changed.

The implementation moved complete open validation into one deferred read
transaction, made absent/pristine rollback fail closed with zero entropy, used
no-create opens for existing databases, and revalidated exact retry inside one
immediate transaction. The final authority suite passed 23/23 and all packet
gates.

## Blocking Review Finding

The split existing-database connection helpers omitted explicit
`journal_mode=WAL` enforcement. A restored valid database in DELETE mode could
open and later write without the required durability configuration. This became
T202A-A004 RED coverage.
