- Account snapshots require binding version one, recompute the account binding
  from exact account/endpoint fields, enforce IMAP/SMTP verified-TLS shapes,
  validate host-kind identity, reject duplicate cleanup IDs, and enforce the
  stored-state and account/credential action matrices.
- Exact generation and trust-epoch relations use checked arithmetic, so
  `u64::MAX -> u64::MAX` is rejected.
- `BoundedUntrustedText` and `ProtocolCapabilities` have private invariant
  fields and no deserialization bypass. Their stable output uses `u64`
  `original_bytes`, `source_sha256`, canonical known-capability order, and
  bounded control-clean unrecognized display values.
- Remote and local search `from`/`to` values enforce 1,024/1,025 limits in the
  lexical preflight before typed allocation.
- `GovernedOperationAuthorization` carries a typed canonical UUIDv4
  `OperationId`.
- The canonical `mismatch + bound` state remains representable for status and
  recovery but does not become authentication-eligible; `invalidated + bound`
  remains invalid.
