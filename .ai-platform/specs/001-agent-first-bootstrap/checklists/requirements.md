# Requirements Checklist

- [x] Product is explicitly agent-first and local-first.
- [x] CLI and MCP reuse one core contract.
- [x] Structured output carries a contract version.
- [x] Unknown providers are not guessed.
- [x] Credentials are absent from discovery inputs and outputs.
- [x] MCP write surface is empty.
- [x] Agent documentation forbids unsupported commands.
- [x] Security documentation treats mailbox content as untrusted.
- [x] Archived desktop lineage and attribution are preserved.
- [x] GitHub CI has passed on the initial public commit.
